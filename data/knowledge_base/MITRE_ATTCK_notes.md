# MITRE ATT&CK — Prototype Notes
Source: https://attack.mitre.org/

Use ATT&CK techniques to describe adversary behavior and connect detected activity with investigation hypotheses. For production use, ingest the official ATT&CK STIX data and retain version/source metadata.

Relevant investigation themes:
- Network service scanning
- Denial-of-service activity
- Valid account and remote-service abuse
- Exploitation of public-facing applications
